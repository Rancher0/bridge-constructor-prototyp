# Bridge Constructor Prototyp

Physikalischer Prototyp im Stil von Bridge Constructor, gebaut mit Matter.js.

## Dateien
- `index.html` – aktueller spielbarer Prototyp (von Grok)

## Features (aktuell)
- Knoten und Balken per Klick setzen
- Materialien: Holz, Stahl, Kabel
- Einfache Stress-Visualisierung (Grün / Gelb / Rot)
- Fahrzeug-Simulation

## Geplant / in Arbeit durch Bot "blödie"
- Bessere Stress-Berechnung
- Budget-System
- Brechende Balken
- Fahrbahn
- Bessere Steuerung (Drag-and-Drop)
- Mehrere Level

Der Bot **blödie** arbeitet an einer erweiterten Version und wird sie hier hinzufügen.

Öffne `index.html` im Browser, um den Prototyp zu spielen.
